# 리서치 산출물 표준 스키마 (Research Output Schema)

> **정본.** 소싱 리서치 산출물(CSV)의 **표준 헤더**를 정의한다. 수집 도구는 raw 수집 후 아래 스키마로 **정규화**해 저장한다.
> **이유**: 소싱처마다 헤더가 제각각이면 비교할 때마다 손으로 맞춰야 한다. 헤더가 하나면 그대로 합쳐진다.

---

## 스키마 ① 소싱-원가 (`*-sourcing-cost.csv`)

> **수집 규모 표준**: 소싱처당 **상품 30개** 기준 (옵션으로 나뉜 행은 상품 아래 딸려온다 — 그래서 행 수는 30보다 많다).
> ⭐ **행 분리 기준 = 옵션**: 한 상품에 옵션(규격)이 여럿이면 **옵션마다 한 행**으로 쪼갠다. 단가는 기본가+옵션 추가금이고 `moq`는 상품 값 그대로다. 옵션이 없는 상품은 한 행이다.

| 컬럼 | 설명 | 예 |
|---|---|---|
| `source` | 소싱처 (레지스트리 기준) | 도매꾹, 도매매 |
| `pattern` | 수집 방식 번호 — 이 팩은 ① 국내 도구(도매꾹·도매매) 하나 | ① |
| `item` | 품목명 | 스테인리스 S자 고리 |
| `origin` | **원산지 (필수)** — 데이터 없으면 공란+주석 아닌 공란 유지(추정 금지) | 국내산 / 중국(수입) |
| `material` | 재질 | SUS304 / 아연도금 강철 |
| `spec` | **규격** — 옵션이 있는 상품은 옵션마다 한 행, 옵션명 그대로 + `(옵션)`. 옵션이 없으면 상세의 크기 값, 그것도 없으면 공란(상품명에서 추정해 채우지 않는다) | 소(8-16mm)(옵션) / 3.5mm |
| `manufacturer` | 제조사/브랜드 | 제조사A / 브랜드B |
| `unit_price_krw` | **개당 원가(KRW)** — 조인 키. 낱개는 개당가, 묶음/박스는 묶음가(개당은 `effective_cost_note` 참조) | 18 |
| `moq` | **최소 주문수량** — 도매꾹·도매매의 최소구매수량. 옵션으로 나뉜 행은 상품 값 그대로 | 2 |
| `currency_orig` | 원통화 | KRW |
| `price_orig` | 원통화 가격. **국내(KRW)는 공란**(unit_price_krw와 중복) | (공란) |
| `effective_cost_note` | 비고(판매단위·배송비·옵션 추가금) | 도매꾹 판매단위당 단가. 배송비 3000원 |
| `source_ref` | URL | https://domeggook.com/12345678 |
| `collected_at` | 수집일 | 20260802 |
| `weight_g` | **개당 중량(g)** — 국제 운임 계산의 입력(kg 기준). 사이트가 표시할 때만 채움 | (공란) |
| `volume_cm3` | **개당 부피(cm³)** — 국제 운임 계산의 입력(CBM 기준). 길이×폭×높이를 사이트가 표시할 때만 채움. 없으면 공란(추정 금지 — 임의로 치수 곱해 계산하지 않는다) | (공란) |
